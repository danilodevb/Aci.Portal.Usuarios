

\# Portal de Usuarios - ACINPRO



Repositorio del desarrollo del portal de usuarios de ACINPRO.



El proyecto contiene tres representaciones del mismo desarrollo, organizadas según su enfoque de implementación:



\## Estructura del proyecto



\### 1. mockups.html

Prototipo inicial que define la estructura visual, navegación y comportamiento esperado del portal.



\### 2. Login-HTML

Implementación funcional desarrollada con HTML, CSS y JavaScript, incorporando estilos y funcionalidades detalladas.



\### 3. Login-React

Implementación del mismo proyecto utilizando React JS y TypeScript, conservando la estructura visual y las funcionalidades de la versión HTML.



\## Objetivo



Mantener las diferentes etapas de implementación del portal en un único repositorio, facilitando su consulta, seguimiento, comparación y evolución.



\## Tecnologías



\- HTML5

\- CSS3

\- JavaScript

\- React JS

\- TypeScript
